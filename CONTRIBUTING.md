# Contributing to PrepTrack

Thanks for considering a contribution.

## Before opening a pull request

1. Search existing issues to avoid duplicate work.
2. For a substantial change, open an issue first to discuss the proposed approach.
3. Keep the app dependency-free unless a dependency is clearly justified.
4. Never add analytics, tracking or remote data collection without explicit project discussion and clear user consent.
5. Keep user-entered content safely escaped before rendering.

## Pull request checklist

- [ ] The change solves one clearly described problem.
- [ ] UI works on a narrow mobile viewport and desktop.
- [ ] Keyboard navigation and labels remain usable.
- [ ] README or documentation is updated when needed.
- [ ] Manual test steps are included in the pull request.

## Development

Open `index.html` directly or use `python -m http.server 8000`. No build step is required.
