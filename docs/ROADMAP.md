# Roadmap

This roadmap is a proposal, not a promise or a claim that features are already implemented.

## Near term
- [ ] Add automated tests for data validation and accuracy calculations.
- [ ] Add subject-wise and date-range summaries.
- [ ] Improve screen-reader announcements for newly added/deleted records.
- [ ] Add configurable scoring rules for different exam formats.

## Later
- [ ] Optional dark theme.
- [ ] Optional localization framework.
- [ ] User research with consent and privacy-preserving feedback.

## Project principles
- Offline-first by default.
- No hidden telemetry.
- Exportable user data.
- Small, understandable changes.
